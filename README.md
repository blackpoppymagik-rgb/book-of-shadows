# Book of Shadows

Black Poppy Magik Apothecary

A deploy-ready static Book of Shadows app with:

- Landing page
- Moon Current
- Tarot Card of the Day
- Spell of the Day
- Chant of the Day
- Beauty Affirmation
- Self-Care Ritual
- Sacred Act of Kindness
- Snarky Baby Witches Quote of the Day
- Ritual Journal
- Dream Journal
- Signs & Synchronicities Journal
- Local saved archive

## Deploy to GitHub Pages

Upload these files to the root of the `book-of-shadows` GitHub repository:

- `index.html`
- `README.md`

Then set:

Settings → Pages → Deploy from a branch → main → /root
